# لانچر Paydar Samp (Android)

این پروژه لانچر ساده و قابل شخصی‌سازی Paydar Samp است. نیازی نیست روی کامپیوتر خودتان Android SDK نصب کنید؛ گردش‌کار GitHub Actions می‌تواند APK آزمایشی را در فضای ابری بسازد.

## ساخت APK بدون نصب SDK
1. یک مخزن جدید در GitHub بسازید.
2. محتویات این پوشه را در مخزن بارگذاری کنید.
3. وارد تب **Actions** شوید و گردش‌کار **Build Paydar Samp APK** را اجرا کنید (Run workflow).
4. پس از پایان موفق، از بخش **Artifacts** فایل `PaydarSamp-debug-apk` را دانلود کنید و APK داخل آن را روی گوشی نصب کنید.

## تنظیم IP
در برنامه IP و پورت قابل ویرایش است. IP فعلی روی `10.29.2.204` و پورت روی `7777` قرار داده شده، اما این IP خصوصی است و فقط در همان شبکه محلی قابل استفاده است. اگر شبکه گوشی با کامپیوتر متفاوت باشد، این آدرس کار نمی‌کند.

## محدودیت اتصال
دکمه اتصال آدرس را کپی می‌کند و تلاش می‌کند URI استانداردشده‌ی `samp://IP:PORT` را باز کند. باز شدن واقعی بازی وابسته به نصب بودن یک کلاینت اندرویدی سازگار است؛ این لانچر خودش موتور بازی SA-MP را شامل نمی‌شود. ممکن است لازم باشد در فایروال ویندوز پورت UDP سرور را مجاز کنید.

این خروجی Debug است و با کلید آزمایشی امضا می‌شود؛ برای انتشار عمومی در فروشگاه، امضای Release جداگانه لازم است.
